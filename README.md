# Suzuri（硯）

**在 iPhone 上写作、配图、发布 Telegraph 文章的本地客户端。**

Telegraph (telegra.ph) 是 Telegram 团队出品的极简写作平台：无需注册，打开页面即可阅读，一个链接就能分享。它是很多人用来写长文、公告、随笔与图文故事的地方。Suzuri 的想法很简单——让发 Telegraph 像在 Notes 里写字一样自然。

## 这个应用是做什么的

- **写作**：一个顺手的块式编辑器。段落、标题、引用、列表、代码、分割线、图片，都在同一块画布里；键盘驱动，光标在区块间平滑流动；草稿自动保存，退出不丢字。
- **配图**：选一张照片，压缩后自动上传到图床，以带图注的图片块插入文章。官方图片上传在 2024 年被 Telegraph 关闭，所以 Suzuri 内置图床方案：默认使用匿名且免注册的 qu.ax，也支持自部署的 Telegraph-Image（Cloudflare Pages + Telegram 频道中转，图片永久存储）或任何兼容官方上传协议的图床。
- **发布与再编辑**：匿名账号一键发布，链接即所得；已发布的文章可以随时拉回来继续改，改完再更新。
- **管理**：自己发过的文章列表、浏览量、服务器镜像切换（telegra.ph / graph.org / legra.ph），在网络的边缘情况里也能发出去。

## 想做成什么样

- **纯正的 iOS 质感**：SwiftUI + 液态玻璃。iOS 26 上使用原生 Liquid Glass，旧系统自动降级为同源的玻璃模拟层，视觉不打折。
- **克制的品牌色**：主色 `#BE4041`（一种偏朱红、沉稳不艳俗的红色），配一套从浅到深的同色相衍生色板。红色只出现在最重要的地方：发布按钮、焦点区块、链接。
- **不廉价**：背景是带色相的渐变 + 极慢呼吸的品牌色光斑 + 顶部微光，而不是平涂的灰；动画统一使用弹簧曲线（`spring(0.32, 0.82)`），区块切换、选区、插入删除全部顺滑过渡。
- **零第三方依赖**：只用系统框架（SwiftUI / URLSession / SwiftData / Keychain），干净、可控、安全。

## 计划

1. **地基**：工程骨架、API 客户端、匿名账号、发布闭环——能发出一篇纯文字文章
2. **配图**：图床抽象层、图片压缩上传、图片块插入——能发一篇带图文章
3. **编辑器**：完整块编辑交互——拆分、合并、类型互转、多选、斜杠命令，纯键盘写完一篇结构化文章
4. **视觉**：液态玻璃系统、品牌色板、统一动画——亮暗模式都好看
5. **打磨**：拉回再编辑、草稿、设置、错误处理、签名上架——能从 App Store 装到手机
